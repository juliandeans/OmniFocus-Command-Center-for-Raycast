# Media Assets

This directory is prepared for screenshots and visual assets for the repository `README.md` and documentation.

## Recommended Screenshots

When preparing screenshots for the public GitHub release, capture the following views:

| Filename                | Command / View   | Description / Caption                                        |
| ----------------------- | ---------------- | ------------------------------------------------------------ |
| `open-project.png`      | **Open Project** | Jump to any active OmniFocus project directly from Raycast.  |
| `search-tasks.png`      | **Search Tasks** | Search open tasks across projects and Inbox with filters.    |
| `add-task.png`          | **Add Task**     | Create tasks with project, tags, dates, flags, and notes.    |
| `inbox.png`             | **Inbox**        | Triage OmniFocus Inbox items without navigating the sidebar. |
| `demo.gif` _(optional)_ | Walkthrough      | Brief animated GIF demonstrating keyboard-first workflow.    |

## Important Privacy Guidelines for Screenshots

> [!IMPORTANT]
> **Use disposable dummy data only.**
> Never take screenshots containing personal tasks, real project names, client information, work notes, private dates, or credentials. Create a separate test perspective or disposable test items (e.g., "Plan summer vacation", "Buy groceries", "Quarterly review") for media capture.

## Image Recommendations

- **Format**: PNG (clean text and borders)
- **Resolution**: 2x Retina scale (standard macOS screenshot)
- **Window Frame**: Standard Raycast window with shadow (default macOS window capture: `Cmd + Shift + 4`, then `Space`)

## Activating in README.md

Once the PNG files are added to this directory, uncomment the screenshot section in `README.md`.
